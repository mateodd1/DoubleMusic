# Project scope and authorized use

DoubleMusic is a server for organizing and playing your own music library. It is intended for your own recordings, public-domain content, or material whose use is permitted by the applicable license, authorization, or legal exception.

The local library is enabled by default. External connections are disabled and must be explicitly enabled through `external.enabled`. The API supports extensions for interfaces and services you are authorized to access. Administrators configure those connections and their credentials outside the repository.

The repository distributes the server, its API contracts, and an example that generates its own sample audio. It does not distribute commercial recordings or platform-specific connectors. Recordings placed in a library by its administrator are separate from the project's code.

A switch or generic API cannot certify the permissions for every piece of content or the terms of every service. A specific connection must respect the applicable authorizations and terms. [WIPO explains rights, licenses, and permitted uses](https://www.wipo.int/en/web/copyright/faq-copyright). In Spain, [Article 17 of the Intellectual Property Act](https://www.boe.es/buscar/act.php?id=BOE-A-1996-8930#a17) establishes exploitation rights and provides for exceptions set out in the law.

Content rights, external service terms, and dependency licenses are separate matters. API documentation does not grant rights over third-party catalogs or replace a review of a particular use.
